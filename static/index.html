README

使用说明

  1. 上传影片。支持 MP4、MKV、MOV 等常见格式。文件不会离开本机。
  2. 框选字幕区域。拖动橙色框，使其只覆盖字幕出现的位置。点「自动识别」可让程序先找一次。
  3. 选择范围、语种与精度。可以只提取视频中的一段；用播放器下方的 −10/−5/−1、+1/+5/+10 秒按钮精确定位，再点「起点取当前 / 终点取当前」。字幕时间仍按原视频输出。
  4. 字幕同步（新）。顶部切到「字幕同步」，载入纯净视频和 SRT/ASS 字幕；可先选择原硬字幕视频做音频自动对齐，再用整体偏移或偏移点微调（起点会带动后续字幕，终点只改该条结束时间）；支持 ±1/5/10 秒按钮和 ←/→ 每次 5 秒跳转。浏览器无法播放的编码可点「兼容预览」转成本机 H.264 预览，预览后导出。
  5. 字幕内封（新）。顶部切到「字幕内封」，选择纯净视频和 SRT/ASS 字幕，设置语言、标题和默认轨道，封装成 MKV。界面会显示上传和封装进度；视频和音频直接复制，不重新编码。
  6. 字幕翻译（新）。顶部切到「字幕翻译」，上传日文或英文 SRT/ASS/SSA，选择繁体或简体中文。翻译会保留时间轴和大部分样式；需要联网，字幕文本会发送到在线翻译服务。
  7. 校对并导出。点击行可跳转视频；⌘/Ctrl 点击多选，Shift 连选。识别设置会显示当前字幕区域，可输入 X/Y/宽/高百分比精确定位，并保留最近使用过的历史区域，可一键恢复。删除、合并、平移、改文字和时间都可撤销/重做（⌘Z / ⇧⌘Z）；时间显示精确到毫秒；清理语种和清理重复都会先弹窗展示并逐项勾选；播放器支持音量和静音。
关于准确率

识别质量取决于字幕字号、背景复杂度和视频清晰度。若画面内文字混入结果，先收紧字幕框，再开启「过滤画面原有文字」。字幕中的空格会保留；多行字幕会自动合并；低分辨率素材会自动放大后再做 OCR。ASS 默认使用楷体、字号 50、边框 2，并自动按画面高度设置字号。
